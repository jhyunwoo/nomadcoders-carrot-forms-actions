# Next.js Boilerplate

## Features
- Next.js 14
- TypeScript
- Drizzle ORM
- Auth.js (Beta)
- Prettier
- PostgreSQL
- TailwindCSS
- Yarn PnP

## Command Line Interface
### Development
```bash
yarn dev
```

### Build
```bash
yarn build
```

### Start
```bash
yarn start
```

### Lint
```bash
yarn lint
```

### DB Push
```bash
yarn db:push
```

### DB Studio
```bash
yarn db:studio
```

## Project context and engineering approach

This repository is a learning implementation built from a full-stack Next.js baseline. It is used to explore form handling and server-driven application patterns while retaining a production-oriented authentication and database setup.

The project uses Next.js and TypeScript for the application layer, Auth.js for identity, Drizzle ORM and PostgreSQL for persistence, and Tailwind CSS for UI work. The documented scripts make it possible to reproduce the database and development environment while iterating on the course exercises.
